## 夜勤サバイバー（ヴァンサバ風ゲーム）

`vansaba/index.html` をブラウザで開くだけで遊べます（インストール不要・1ファイル完結）。

深夜の工場に湧き出す「不良品」から逃げ回り、落ちたネジを拾ってレベルアップ。朝6時（10分）まで生き延びればクリアです。

### ステージ（タイトル画面で選択）

| 難易度 | ステージ | 敵（ザコ／速い／硬い／ボス） | 特徴 |
| --- | --- | --- | --- |
| 初級 | ネジ工場 | バリ虫／切粉／錆塊／品質監査官 | 基本のステージ |
| 中級 | 電子機器工場（SMT実装ライン） | チップ立ち／はんだボール／足浮きIC／リフロー炉の番人 | 敵のHP1.35倍・数1.3倍。床は基板 |
| 上級 | 組立ライン | チョコ停／不良札／不良ロット／タクトタイム大王 | 敵のHP1.8倍・数1.6倍。ベルトコンベアで流される。ボスは時間とともに加速 |

| 最上級 | 管理職モード（初級・中級・上級をすべて定時退勤で解放） | 3工場の敵がまとめて出る／ボス3体が順番に巡回 | 敵のHP2.4倍・数1.9倍・夜勤手当×3。ベルトコンベアあり |

- 超大ボス「リコール大魔王」：上級（経過9:00）と管理職モード（5:00・9:00）に出現。出現時に警報、画面上部に専用HPバー。全方向弾と狙い撃ちの弾を撃ち、手下を呼ぶ。倒すと特別報奨金（¥5,000×夜勤手当）

ステージの強さは `index.html` の `STAGES` で調整できます。

| 操作 | キー |
| --- | --- |
| ステージ選択 | タイトル画面のカード or 数字キー 1〜3 |
| 移動 | WASD / 矢印キー / 画面をドラッグ（スマホ） |
| 攻撃 | 自動 |
| レベルアップ時の選択 | クリック or 数字キー 1〜3 |
| 一時停止 | P / Esc（BGMの音量もここで調整） |
| BGM／効果音のオン・オフ | 画面右上の「曲」「音」ボタン |

- 武器：リベット銃・回転スパナ・溶接アーク・高圧放電（各Lv5まで）
- 強化：安全靴・健康診断・マグネット・潤滑油・熟練の手袋・ヘルメット
- 毎分「切粉の嵐」、2分・5分・8分にボス出現
- BGM：3曲から選択（タイトル画面・休憩画面）。どれも音源ファイルなしのオリジナル曲で、ブラウザ内で自動演奏
  - 夜想：静かなピアノとコーラス
  - 疾走：ドラムと刻むシンセベース、弦のスタッカート、金管風メロディのハイブリッド・オーケストラ
  - 幻想：ハープの分散和音とフルート、チェレスタによる3拍子のワルツ
  - ステージが上がるほどテンポが速くなり調も変わる。ボス出現中は低いリズムが加わる

### 給料と育成

- 1回遊ぶごとに給料が出る：基本給（時給1,200円 × 工場時刻での勤務時間）＋撃破手当（1体5円）＋定時退勤手当（クリア時3,000円）。これに夜勤手当の倍率（初級×1・中級×1.5・上級×2）をかける
- 結果画面に給与明細を表示。給料は貯金され、タイトル画面の「設備投資・福利厚生」で使う
  - 持ち込み工具：最初から武器を装備・レベルを上げた状態で始める（リベット銃・回転スパナ・溶接アーク・高圧放電）
  - 福利厚生：体力・威力・攻撃間隔・移動速度・回収範囲・経験値・幸運・時給がずっと上がる
- ラッキーボーナス：レベルアップ時、武器のカードがまれに金色の「ラッキー！」になり、選ぶと3段階まとめてレベルアップ（基本8%、幸運のお守りで+3%ずつ）
- 金額や値段は `index.html` の `WAGE`・`KILL_PAY`・`CLEAR_PAY`・`SHOP` で調整できる

### 自己投資・覚醒・表彰状

- 武器6種（リベット銃・回転スパナ・溶接アーク・高圧放電・自動ドリル・フォークリフト）と強化8種（安全帯・改善ノートを追加）。最初はどれも Lv5 まで
- 「設備投資・福利厚生」の **自己投資** で資格を取ると上限が上がる
  - 講習：武器の上限 Lv5 → Lv10（¥4,000）／スキルアップ研修：強化の上限 Lv5 → Lv10（¥8,000、Lv6以降は効き目半分）
  - 検定1級（¥1,000,000）：その武器が覚醒できるようになる
- 覚醒：検定1級を取った武器が Lv10、相棒の強化が Lv5 になると、レベルアップ時に「覚醒」カードが出る
  - リベット銃＋潤滑油 → 全自動リベッター「嵐」（全方向16連射＋小爆発）
  - 回転スパナ＋熟練の手袋 → 大車輪レンチ（巨大スパナ6本が伸び縮みして回転、光の残像）
  - 溶接アーク＋健康診断 → プラズマ溶断（範囲拡大＋3秒ごとに青白い大爆発）
  - 高圧放電＋マグネット → 雷神の配電盤（敵から敵へ連鎖する稲妻）
  - 覚醒の瞬間はスロー・光の柱・「覚醒」の大文字の演出
- タイトル画面の「覚醒の試運転」で、覚醒装備4つをそろえた状態を体験できる（給料・記録・貯金は増えない）
- HPが満タンのときに「缶コーヒー」を選ぶと、飲まずに我慢して ¥150 を貯金（給与明細の拾得金に入る）
- 取れる改善がなくなると「表彰状」カード（威力+2%・最大HP+5）が何度でも出るので、Lv99 まで選択肢がなくならない

### アイテムBOXとピンチ救済

- フィールドに赤い工具箱（?）が置かれ、触れると開く。画面外の箱は画面端の矢印で場所がわかる
  - 強力マグネット（ネジ全回収）／夜食の弁当（HP+30）／救急箱（HP全回復）／大入り袋（💰 ¥300〜¥800）／非常停止ボタン（6秒間敵が停止）／5S一斉清掃（画面内の敵に大ダメージ）／栄養ドリンク（10秒間 移動・攻撃アップ）
- 敵がまれに小銭（¥）を落とす。拾った額は給与明細の「拾得金」に入る
- HPが30%を切ると近くに白い救急箱（HP全回復）が届く（40秒に1回まで）。HPが35%未満のレベルアップでは4枚目に救急箱カードが出る
- ボス撃破時はスローモーション・白フラッシュ・衝撃波（画面内のザコを一掃）・「撃退」の判子の演出。金色の特別ボーナス箱を落とす
- タイトル画面と休憩画面の「ルール」で、ルールと給料の内訳を確認できる。休憩画面には今夜の給料の途中経過も出る

### キャラ画像の差し替え

`vansaba/ChatGPTキャラデザ依頼.md` の依頼文を ChatGPT に貼って画像を作り、`vansaba/sprites/` に入れて `index.html` の `SPRITE_FILES` にファイル名を書くと、そのキャラが画像に置き換わります。

調整したい数値は `index.html` の `ETYPES`（敵）、`WR / WS / WW / WK`（武器性能）、`SHIFT`（クリア時間）にまとまっています。
