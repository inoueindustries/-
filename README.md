## 夜勤サバイバー（ヴァンサバ風ゲーム）

`vansaba/index.html` をブラウザで開くだけで遊べます（インストール不要・1ファイル完結）。

深夜の工場に湧き出す「不良品」から逃げ回り、落ちたネジを拾ってレベルアップ。朝6時（10分）まで生き延びればクリアです。

| 操作 | キー |
| --- | --- |
| 移動 | WASD / 矢印キー / 画面をドラッグ（スマホ） |
| 攻撃 | 自動 |
| レベルアップ時の選択 | クリック or 数字キー 1〜3 |
| 一時停止 | P / Esc（BGMの音量もここで調整） |
| BGM／効果音のオン・オフ | 画面右上の「曲」「音」ボタン |

- 武器：リベット銃・回転スパナ・溶接アーク・高圧放電（各Lv5まで）
- 強化：安全靴・健康診断・マグネット・潤滑油・熟練の手袋・ヘルメット
- 敵：バリ虫・切粉（速い）・錆塊（硬い）・品質監査官（ボス）
- 毎分「切粉の嵐」、2分・5分・8分にボス出現
- BGM：ピアノのアルペジオとコーラスによる静かなオリジナル曲（音源ファイルなし・ブラウザ内で自動演奏）。ボス出現中は低いリズムが加わる

### キャラ画像の差し替え

`vansaba/ChatGPTキャラデザ依頼.md` の依頼文を ChatGPT に貼って画像を作り、`vansaba/sprites/` に入れて `index.html` の `SPRITE_FILES` にファイル名を書くと、そのキャラが画像に置き換わります。

調整したい数値は `index.html` の `ETYPES`（敵）、`WR / WS / WW / WK`（武器性能）、`SHIFT`（クリア時間）にまとまっています。
