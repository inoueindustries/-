# ChatGPT キャラデザ依頼文（夜勤サバイバー）

ChatGPT（画像生成が使えるモデル）に、下の「共通の指示」と「キャラ別の指示」を1体ずつ貼って依頼してください。
5体すべて同じチャットで続けて頼むと、絵柄がそろいやすくなります。

---

## 共通の指示（最初に1回だけ貼る）

```
ブラウザで動く2Dアクションゲーム「夜勤サバイバー」のキャラクター画像を作ってください。
舞台は深夜の工場。プレイヤーは夜勤の作業員で、工場に湧き出す「不良品」たちから逃げ回ります。

絵柄のルール（全キャラ共通）:
- ちびキャラ、2頭身、まるっこいシルエット。かわいさ優先、怖さはゼロ
- 大きな黒目にハイライト、ほっぺに薄いピンク
- 太めの濃い色アウトライン、フラットな塗り、影は1段だけ
- 斜め上から見下ろした正面寄りの向き（体はやや右向き）
- 背景は透明（PNG）。影・地面・文字・枠は描かない
- 1枚に1体だけ、画像の中央に、上下左右に1割ほど余白
- 正方形 1024×1024
- 小さく縮小（64px程度）しても形がわかるように、細かい描き込みは控えめ

色のトーン（ゲーム画面に合わせたい）:
- 床は暗い紺グレー #161b21
- 安全イエロー #f2c230 / ナトリウム灯オレンジ #ff8a3d / 溶接の水色 #7fe3ff / 警告の赤 #e5484d
```

## できた画像をゲームに入れる方法

1. 画像を上のファイル名で保存し、`vansaba/sprites/` フォルダに入れる
2. このチャット（Claude）に「画像を入れたので反映して」と伝える
   （自分でやる場合は `index.html` の `SPRITE_FILES` の `null` を `'sprites/player.png'` のように書き換える）

画像が入っていないキャラは、今までどおりプログラムで描いたキャラが表示されます。
