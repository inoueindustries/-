# VOICEVOXでボイスを作る手順（夜勤サバイバー）

VOICEVOX は無料で使える日本語の音声合成ソフトです。自然な声で、少年っぽい声のキャラクターもいます。
作った音声ファイルをこのフォルダ（`vansaba/voice/`）に入れると、ゲームのレベルアップ時のボイスがその声に変わります。

## 1. VOICEVOX を入れる

1. 公式サイト https://voicevox.hiroshiba.jp/ から、お使いのPC用（Windows／Mac）をダウンロードしてインストール
2. 起動する

## 2. セリフを読み込んで、キャラを選ぶ

このフォルダにある3つのテキストファイルを使います（1行が1セリフ、各6行）。

| ファイル | 声 | おすすめのキャラ（例） |
|---|---|---|
| `セリフ_男性.txt` | 男性 | 青山龍星（ノーマル）、玄野武宏（ノーマル） |
| `セリフ_女性.txt` | 女性 | 冥鳴ひまり（ノーマル）、春日部つむぎ（ノーマル） |
| `セリフ_少年.txt` | 少年 | 白上虎太郎（ふつう） |

1. VOICEVOX のメニュー「ファイル」→「テキスト読み込み」で、上のテキストファイルを1つ選ぶ
2. 読み込まれた6行すべてのキャラクターを、上の表のキャラに変える
3. 声の高さや抑揚は、好みで調整してOK（元気な感じなら「抑揚」を少し上げる）

## 3. 書き出す

1. メニュー「ファイル」→「音声を全て書き出し」
2. 書き出し先のフォルダを、声ごとに分けておくと楽です（例：`男性`、`女性`、`少年`）

ファイル名はそのままで大丈夫です。こちらで名前を付け直して登録します。

## 4. GitHub にアップロードする

1. GitHub のリポジトリを開き、ブランチ `claude/vansaba-style-game-jmblds` を選ぶ
2. `vansaba/voice/` フォルダで「Add file」→「Upload files」
3. 書き出したファイルをまとめてドラッグして、「Commit changes」
4. Claude に「ボイスを入れた。男性は○○、女性は○○、少年は○○」と、使ったキャラ名を伝える

## 5. 注意（利用規約）

- VOICEVOX の音声を使うときは、**「VOICEVOX:キャラ名」のクレジット表記が必要**です（例：`VOICEVOX:青山龍星`）。ゲームのルール画面に表記を入れます。
- キャラクターごとに利用規約があります。公開・共有する前に、公式サイトの各キャラのページで確認してください。
