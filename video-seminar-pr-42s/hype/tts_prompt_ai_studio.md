# 激しい版ナレーション｜Google AI Studio（Gemini TTS）用の台本

AI Studio の「遊び場」→ 音声生成（generate-speech）で使う。
AIっぽさの主な原因は「声の選び方」と「1つの枠に全文を詰めること」。下の手順で1文ずつ演出をつける。

## 1. 声を選ぶ（右側「スピーカー設定」）

- 説明に「低音」「深い」「力強い」「落ち着いた」とある**男性の声**を2〜3個選び、1枠目だけで聞き比べる
- 「タヴィ」は「静かで親密・中高音域」なので、この動画には向かない

## 2. 声の人物像（「音声デザイン」やスタイル欄に書ける場合）

```
映画の予告編のナレーター。40代の日本人男性。
低く太い、胸から響く声。叫ばずに、静かな凄みで押す。
言葉の頭を少し強く当て、語尾は下げて言い切る。
一文ごとに一拍の間。同じ抑揚を繰り返さず、機械的な一定のリズムにしない。
息づかいを少しだけ残し、生身の人が語っているように。
```

## 3. 枠は7つに分ける（1枠＝1文）

- 画面に出る文字（「1ヶ月で1000人」「本気の仲間を募集」など）は**入れない**。読むのはナレーションだけ
- 読み間違いを防ぐため、数字と英語はかなで書いている（いっかげつ・せんにん・いちじかん・ズーム）
- `<short pause>` は短い間。「＋式」から入れられるほかの合図（息など）があれば足してよい
- 秒数は動画に収めるための目安。多少はみ出しても、こちらで位置を調整できる

| 枠 | 話し方の指示（スタイル欄） | 本文 | 目安 |
|---|---|---|---|
| 1 | 低く静かに、相手の目を見て問いかける。「満足ですか？」は語尾を上げすぎず、低く鋭く。 | あなたは<short pause>このままの人生で<short pause>満足ですか？ | 4.5秒以内 |
| 2 | 決意を込めて、一語ずつ置くように。最後の「挑む」は低く、強く言い切る。 | いっかげつで、せんにんの組織づくりに<short pause>挑む。 | 4.5秒以内 |
| 3 | 自信をもって。「本気で」に重心を置き、静かな凄みで。 | 結果を出してきた人たちと<short pause>本気で組む。 | 5秒以内 |
| 4 | たたみかける。三つの言葉をだんだん熱く、少しずつ速く。「夢を追いたい」で一番熱く。 | 現状を変えたい。<short pause>成長したい。<short pause>仲間と、夢を追いたい。 | 4.8秒以内 |
| 5 | 一度声を落としてから、「あなただ」で真っすぐ突き刺す。 | 求めているのは<short pause>本気で挑戦する<short pause>あなただ。 | 4秒以内 |
| 6 | 一番の山場。「説明会ではない」は低く断言。間を取ってから「人生を変える、挑戦のスタートだ」を力強く。叫ばない。 | これは、説明会ではない。<short pause>人生を変える、挑戦の、スタートだ。 | 4.8秒以内 |
| 7 | 熱を残したまま、最後は低く温かく。「待っている」は一拍置いて、ゆっくり。 | まずは、いちじかん。<short pause>ズームセミナーで<short pause>待っている。 | 3.8秒以内 |

## 4. 作り方のコツ（AIっぽさを消す）

- 同じ枠を**3回ほど生成して一番いいもの**を選ぶ（毎回読み方が変わる）
- 抑揚が平坦なら、指示に「もっと間を取って」「語尾を下げて言い切る」と足す
- 速すぎる・機械的なら「少しゆっくり、一語ずつ噛みしめるように」と足す
- 大げさすぎるなら「叫ばない。声量ではなく低さと間で迫力を出す」と足す

## 5. 書き出し

- 7枠を1本の音声でダウンロード（wav）して添付すれば、こちらで文ごとに切り分けて動画に合わせる
- 枠ごとに別ファイルでもよい（n01.wav〜n07.wav の順番がわかる名前で）
