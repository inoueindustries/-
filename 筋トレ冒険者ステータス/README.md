# 筋トレ冒険者ステータス（スマホ／PC共通のWebアプリ）

スプシ『食事・運動・体組成ログ_まとめ』をデータベースとして読み、ドラクエ風のステータス画面を表示する Google Apps Script（GAS）の Webアプリです。

- **スマホ**：URLを開いて「ホーム画面に追加」すると、アプリのようにワンタップで開けます。画面下のコマンド（つよさ／ぶい／けいけん／きろく）で切り替えます
- **PC**：URLをブックマークします。横に広い画面では全部いっぺんに表示されます
- サーバー代はかかりません。データは自分のGoogleアカウントの中だけで完結します（公開設定は「自分のみ」）

## いちばん簡単な使い方：claude.ai のページ（デプロイ不要）

**https://claude.ai/artifact/PehPmKppwSA1fbYj51WK58**

- 開いた人の Google Sheets 連携でスプシを読み、その場で計算して表示します。GASのデプロイは不要です
- **iPhone**：Claudeアプリ、またはSafariで claude.ai にログインして開く（Safariなら「共有 → ホーム画面に追加」でアプリのように置けます）
- **PC**：ブラウザでリンクを開いてブックマーク。横長の画面では3列でまとめて表示します
- 初めて開いたときだけ「Google Sheets の利用を許可しますか」と聞かれるので、許可してください
- 公開範囲は「自分のみ」です。読めるのは、スプシを開ける Google アカウントでつないでいる人だけです
- 中身は `claude-page.html`。これは `index.html` と `web-compute.js` から `python3 build_claude_page.py` で作っています

以下のGASのWebアプリは、claude.ai を使わずに見たいとき用の別ルートです（画面は同じ）。

## スマホのホーム画面に置く専用アプリ版（quest/）

claude.ai のページはホーム画面に置くとアイコンが Claude のマークになり、上に Claude のバーが出ます。専用アプリ版は、キャラのアイコンで全画面表示になります。

- 置き場所：リポジトリの `quest/`（GitHub Pages で `https://inoueindustries.github.io/-/quest/`）。`python3 build_claude_page.py` で `index.html` から作ります
- データ：スプシの Apps Script（下の「導入手順」の `Code.gs`）を「全員」に公開し、`setupAppKey` で作った合言葉つきURLから読みます。合言葉つきURLはスマホの中にだけ保存し、リポジトリには置きません
- 手順
  1. 下の「導入手順」で `Code.gs` を貼り、ウェブアプリとしてデプロイ（アクセスできるユーザー：**全員**）
  2. Apps Script で `setupAppKey` を1回実行し、実行ログに出た合言葉（`key=…`）をコピー。あわせて「デプロイ → デプロイを管理」に出る、`/exec` で終わる「ウェブアプリ URL」もコピー
  3. iPhone の Safari で `quest/` のページを開き、「共有 → ホーム画面に追加」
  4. ホーム画面のアイコンから開き、① にウェブアプリ URL、② に合言葉を貼って「ほぞんして よみこむ」
- `setupAppKey` を実行したあとは、合言葉のないURLでは何も読めません。もう一度実行すると合言葉が変わります

## 計算のしかた

スプシのダッシュボードのセル位置には頼らず、**『トレーニング・運動ログ』と『経験値・部位負荷マスタ』の生データから毎回計算**しています。シートのレイアウトを変えても壊れにくくするためです。

- 1行ごとの獲得EXP ＝ ログの「基礎獲得EXP」列（空なら 総ボリューム × マスタの基礎EXP倍率）
- 減衰：7日間は100% → 8日目から1日5%ずつ減る → 27日で0%（スプシの式と同じ）
- 17部位への配分：マスタの配分率を掛けて積み上げます。マスタに無い種目は、ログの「部位」列を見て6大部位に入れます
- 列は**見出しの名前で自動で探します**（「日付」「種目」「基礎獲得EXP」「三角筋(中部)」など）

### レベル曲線（ドラクエ風）

Lv n に必要な有効EXP ＝ 15.9 ×（n−1）^1.5

Lvが上がるほど、次のLvまでに必要なEXPが増えます。スプシの「100 EXPごとに1Lv」で Lv42 だった約4,200 EXP が、そのまま Lv42 になるように係数を合わせています。

| Lv | 必要EXP | 次のLvまで |
|---|---|---|
| 10 | 429 | 約70 |
| 20 | 1,317 | 約100 |
| 42 | 4,175 | 約150 |
| 70 | 9,114 | 約200 |
| 99 | 15,426 | 約240 |
| 200 | 44,636 | 約340 |
| 999 | 501,295 | （最大） |

大部位・17部位のLvも同じ曲線です（同じEXPなら同じLv）。

**スプシとアプリは同じ曲線で計算します。** 係数（15.9）と乗数（1.5）は、スプシ『ドラクエ風ステータス・EXP』の **H8〜K8「Lv曲線 係数／乗数」** に置いてあります。ここを書き換えると、スプシの総合・大部位・17部位のLvと、アプリのLvが一緒に変わります。減衰ルール（I5「100%維持期間」、I6「8日目〜減衰率」）も、アプリはこのシートの値を読みます。

### 称号と職業

- **称号**：総合Lvで決まります。スプシ『ドラクエ風ステータス・EXP』の L18:N33 の称号テーブルが元で、アプリもそこを読みます（Lv1 みならい冒険者 → Lv10 かけだし武闘家 → … → Lv700 天地創造の筋神 → Lv999 筋肉の神）
- **レベル上限**：Lv999
- **職業**：いちばん鍛えている大部位で決まります（胸＝重装の騎士、脚＝大地の守護者 など）
- **上級職「万能の勇者」**：6大部位すべてがLv10以上で、いちばん弱い部位のEXPがいちばん強い部位の半分以上になると転職します

名前や数値は、`Code.gs` 冒頭の `QS_CONFIG` を書き換えるだけで変えられます。

### 種目の数（42種目）

入るところが同じ種目は、1つにまとめています。重さや持ち方の違いは「重量」の欄で表します。

| まとめた種目 | まとめる前 |
|---|---|
| 懸垂 | 懸垂（チンニング）、加重懸垂 |
| ダンベルロウ | ワンハンドダンベルロウ、ダンベルベントオーバーロウ |
| ダンベルショルダープレス | アーノルドプレス、ワンアームショルダープレス |
| トライセプスエクステンション | ダンベルフレンチプレス、ダンベルキックバック、ライイングダンベルエクステンション、ワンアームオーバーヘッドエクステンション |
| スクワット | ダンベルスクワット |

チャットのスキルと Gemini は、まとめる前の名前で報告しても、まとめた種目として計算します。

## 導入手順（10分くらい）

1. スプシ『食事・運動・体組成ログ_まとめ』を開き、メニューの **拡張機能 → Apps Script** を開く
2. 左の「ファイル」の **＋ → スクリプト** で `status` という名前のファイルを作り、`Code.gs` の中身を全部貼り付ける
   - すでに別のGASがあっても大丈夫です。ただし、ほかのファイルに `doGet` という関数がある場合は、どちらか一方にしてください
3. **＋ → HTML** で `index` という名前のファイルを作り（`.html` は自動で付きます）、`index.html` の中身を全部貼り付ける
4. 保存（Ctrl+S）
5. 右上の **デプロイ → 新しいデプロイ** を開き、歯車アイコンから **ウェブアプリ** を選ぶ
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**自分のみ**
6. 「デプロイ」を押し、初回はGoogleの承認画面で許可する（「このアプリは確認されていません」と出たら「詳細 → 移動」）
7. 表示された **ウェブアプリのURL** を開くとステータス画面が出ます

### スマホのホーム画面に置く

- **iPhone（Safari）**：URLを開く → 共有ボタン → 「ホーム画面に追加」
- **Android（Chrome）**：URLを開く → 右上の︙ → 「ホーム画面に追加」

※「自分のみ」にしているので、そのブラウザでGoogleにログインしておく必要があります。

### 毎晩の自動記録（EXP日次履歴ログ）

Apps Scriptの画面で、上の関数選択から次の2つを **1回ずつ** 実行します。

1. `backfillHistory` … 過去90日分の履歴をログから計算して、『EXP日次履歴ログ』シートを作ります
2. `setupDailyTrigger` … 毎晩23時台に `recordDailySnapshot` が自動で動き、その日の部位別有効EXPを1行追加します

このシートを使えば、スプシ側でも部位ごとの折れ線グラフが作れます。

### コードを書き換えたあと

**デプロイ → デプロイを管理 → 鉛筆アイコン → バージョン「新バージョン」→ デプロイ** で更新します。URLは変わりません。

URLの末尾に `?format=json` を付けると、画面と同じデータがJSONで返ってきます（ログイン中の自分だけ）。

## チャットでEXPを返すスキル（muscle-quest-exp）

Claudeのチャットで「サイドレイズ 8kg 12回 3セット」のように報告すると、獲得EXP・効いた部位・レベルアップまでの残りEXPを、ドラクエ風に返すスキルです。

```
・サイドレイズ 8kg × 12回 × 3セット = 288kg × 倍率1.2 → 346 EXP
　　└ 三角筋・中部 +294、僧帽筋(上部) +35、三角筋・前部 +17

＊ ちゃんズは かたを きたえた！ 346ポイントの けいけんちを かくとく！
＊ ちゃんズの レベルが あがった！ Lv.42 → Lv.44
＊ つぎの レベルまで あと 102ポイント！
　肩 Lv.17 → Lv.21（1,080 → 1,426 EXP）
```

- 計算はスプシと同じ式です（実質負荷＝体重×自重換算係数＋重量、EXP＝総ボリューム×倍率、Lvは曲線）。ログに入っている実際の行と照合して、同じEXPになることを確認しています
- Google Sheets コネクタがつながっていれば、スプシから「いまの有効EXP」「体重」「Lv曲線の係数」を読んで、レベルアップまでの残りを出します
- 「記録して」と言ったときだけ、トレーニングログに1行追加します（body-fat-tracker が記録を担当しているなら、そちらに任せます）

### 入れ方
1. このフォルダの `muscle-quest-exp.zip` をダウンロードする
2. claude.ai の **設定 → 機能（Capabilities）→ スキル** で、zipをアップロードする
3. スプシを持っているアカウントで、Google Sheets コネクタをつなぐ

中身は `skill/muscle-quest-exp/` にあります。種目や倍率をマスタで変えたときは、`references/master.json` も作り直してください。

## Gemini で同じ返答を出す（Gem のカスタム指示）

`gemini/gem-instructions.md` の中身を、Gemini の Gem の「カスタム指示」に貼り付けてください。Claude のスキルと同じ式・同じ型で返答します。

- Gemini はスクリプトを実行できないため、マスタ全42種目・Lv表・計算用の Python コード・答え合わせ用の例題をプロンプトに入れています
- いまの有効EXPや体重は、スプシを読めればそこから、読めなければ報告文から拾います（「いま4232」のように添えると確実です）
- マスタやLv曲線の係数を変えたら、このファイルも作り直してください
