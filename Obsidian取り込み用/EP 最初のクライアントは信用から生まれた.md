# EP 最初のクライアントは信用から生まれた

> クラウド用・匿名化版。前職・顧問先の会社名は書いていない(記事でも出さない方針で確定)。
> 正本はObsidianに置き、必要ならObsidian側で社名をメモする。

## 一言でいうと

営業で取った仕事ではない。何年も前の日雇いバイトでの縁と、筋を通した恩返しが、独立後の最初の顧問先になった。

## 時系列

| 時期 | 出来事 |
|---|---|
| 40歳前 | 前職で上司から「いい年してしょうもないミスしかしない」「お前みたいな人間はこの会社以外では働けない」と言われ続け、自信を失う |
| 同じころ | 「本当にこの会社以外では働けないのか」「今の実力を外で見てみたい」と思い、会社員を続けながら日雇いバイトを始める |
| 日雇い初日 | 最初の現場が、経験した中で1、2を争うひどさ。前日に派遣会社と現場がもめており、人としてまともに扱われなかった |
| その後 | その現場で一緒に働いた人と仲良くなり、紹介で仕事が広がる(スーパーのオープニング、イベント設営、重機の組み立て・片付け、遺品整理、清掃) |
| 転機 | 初めての遺品整理の仕事をきっかけに、清掃会社から直接仕事を受けるようになる |
| 約1年弱 | 清掃会社の新事業立ち上げをアルバイトとして手伝う。入社の誘いを受けるが、別の仕事をしたくて断る |
| 3年後 | 前職で新工場の施工担当に。清掃会社が工務店を始めたと聞き、恩返しの気持ちで見積もりを依頼。判断は会社に任せ(相見積もり)、その工務店が本工事を受注 |
| その後 | 「また一緒に仕事をしたい」と声がかかる。会社員を辞めようと考えていた時期と重なり、顧問として参画 |
| 現在 | AI導入・業務改善担当の非常勤顧問として支援(独立後の最初のクライアント) |

## 本人の言葉(そのまま使える)

- 「本当にこの会社以外では働けないのか。今の自分の実力を外で見てみたい」
- 「お世話になった会社に、いつか恩返しの意味も込めて仕事を頼みたい」
- 「AIは使いますが、AIを導入するかどうかは御社の業務を見てから」
- 「真面目に働き、仁義を通し、恩には恩を返す」
- 「信用は失うのは一瞬だが、得るのはとても時間がかかる」
- 「信用だけが稼ぐ力ではないが、信用から得られる稼ぐ力はとても大きい」
- 「この方法は万人受けはしないし、数を稼ぎたい人には響かない」

## このエピソードから言えること(教訓)

1. 最初の仕事は、営業テクニックではなく「真面目にやり抜く努力」と「人同士の信頼」からつかめる
2. 顧問先は技術や経歴ではなく、人柄を見て選んでくれた(業界も業種も違う会社)
3. 恩返しはするが、仕事の判断はゆがめない(見積もりを頼むまで。選ぶのは会社)
4. 小さな出会い(最悪の現場の一人)が、何年もたって大きな仕事になる
5. AIが当たり前になった今、「AIが使えます」は売り文句にならない。信用と業務理解が差になる
   - 参考:Claude Codeの発表は2025年2月24日(Anthropic公式)。その1年後の2026年2月24日には、仕事全般向けのエージェント(Cowork・プラグイン)を発表するイベントがあった

### 1分版(自己紹介用・たたき台)

> 40歳前、前の会社で「お前はこの会社以外では働けない」と言われ続けて、自信をなくしていました。本当にそうなのか確かめたくて、休みの日に日雇いバイトを始めたんです。最初の現場は最悪でしたが、そこで出会った人の紹介で仕事が広がり、ある清掃会社にお世話になりました。3年後、会社で新工場の施工会社を選ぶ立場になったとき、その会社が工務店を始めたと聞いて見積もりをお願いし、正式な比較の結果、受注されました。それがきっかけで「また一緒に」と声をかけてもらい、今その会社の顧問をしています。私の最初のお客さんは、営業ではなく信用から生まれました。
